The first working example of the decoupled version of the mh2 prop panel for plugin panel.

This is an official styled plugin for Makehuman 2. The plugin requires Makehuman 2 Plugin version and up  
in order to be loaded.  
  
The goal of this plugin is to load objects onto the existing stag with the base model for posing and more.  
This should include exporting as a scene and also character exporting with props included in pose. (prop states)
