# Prop_Panel_Plugin

The first upload of the prop panel plugin for testing purposes. This will be for Makehuman 2 Official plugins.   
This will fully require MH2 Plugin panel expansion and up in order to operate.   
  
https://github.com/Makehuman-2/Official_MH2-Plugin-Release   
    
    
<img src="resource/prop_tests1.png" alt="Demo Image" width="500">
  
This widget will open only as a plugin but will interact with the main window for prop placement and rendering.  
There should be prop states relating to holding, placed, arranged(locked), and used ultimately.  
    
This is a work in progress, and thus is the first practical testing - since it was decoupled from a full build prior to   
a complete rework of mh2 in relation to plugins.  This is in an unfinished state at present. The Future Goal for this   
plugin is reasonably working by around the end of 2026 aprox with flexibilty.   
   
The type of plugin that this one is, will remain official/fully integrated. This will require Makehuman 2 Plugin panel expansion    
and up in order to load and utilize.  You will be able to add objects in prop file to bring to your scene and manipulate in various    
ways in order to take more realistic renders and export your props with your character.      
  
Place this build inside the mh2_official_tools/prop_panel folder in order to utilize in makehuman2 via the plugin panel.
